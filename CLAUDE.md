# HouseholdOS

HouseholdOS is a React Native mobile app built with Expo and TypeScript.

## Goal

Build the easiest household management app possible.

The app should help roommates, couples, and families manage:

- Pantry inventory
- Fridge inventory
- Grocery shopping
- Shared bills
- Chores
- Household dashboard

The experience should feel effortless rather than like entering data.

## Design Philosophy

The UI should be heavily inspired by Robinhood:

- extremely clean
- large spacing
- minimal colors
- simple typography
- large touch targets
- smooth animations
- only one obvious primary action per screen

Avoid clutter.

Every screen should feel calm.

## Tech Stack

- Expo
- React Native
- TypeScript
- Expo Router
- Zustand
- TanStack Query
- Supabase
- React Native Reanimated

## Coding Style

- Prefer functional components.
- Keep components small.
- Reuse components whenever possible.
- Avoid unnecessary complexity.
- Explain major architectural decisions before making them.
- Never make large changes without summarizing the plan first.

Always prioritize maintainability and clean code.
